# zephyr4772.github.io

Source for [zephyr4772.github.io](https://zephyr4772.github.io). GitHub Pages builds it with Jekyll on every push.

**New post:** add `_posts/YYYY-MM-DD-short-title.md` with this header, then push.

```yaml
---
layout: post
title: "Post title"
description: "One sentence for the index page and link previews."
tag: Agent evals
image: /assets/img/cover.png        # optional, 1300x650 works well
image_alt: "What the image shows"
---
```
